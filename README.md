# Space & Beyond QA

Proyecto de automatización de pruebas desarrollado para la validación de la plataforma Space & Beyond utilizando Testim.io.

- Google Chrome
- Mozilla Firefox
- GitHub

## Estructura del Repositorio

/datos
/evidencias
/reportes

## Shared Groups
- Login Setup
- Teardown

## Objetivo
Automatizar y documentar casos de prueba funcionales de la aplicación Space & Beyond, registrando evidencias e incidencias encontradas durante el proceso.

## Ejecución
1. Abrir Testim.
2. Ejecutar Smoke Test.
3. Ejecutar Suite completa.
4. Revisar evidencias y reportes.
